# Strain-Gauge-DAQ
Baja SAE Strain Gauge DAQ PCB (WIP)

Designing a strain-gauge DAQ PCB for the suspension members of my school's Baja SAE off-road kart. The board will be designed around an STM32 MCU to process multiple strain gauge bridge signal inputs, and will convert and export the captured data to a formatted CSV file on a micro SD card. This board features signal conditioning via instrumentation amplifiers, 4-channel MUXs, a voltage ref IC, and a high-speed op-amp buffer. The board also features an LCD display for navigation.

The current stage of this project is in the R&D phase; the PCB schematic design is set to be finalized by Dec 1st, 2026.
"Claude's Revision" folder is used purely for reference and testing. It is also very handy at reading datasheets and application notes.
