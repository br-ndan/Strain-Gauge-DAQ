Strain Gauge PCB Change Log

What was changed in CLAUDE TEST – straingaugesystem – brendan copy.kicad_sch against each item on the Strain Gauge PCB Fix List, and the reasoning behind each choice. Every edit went through Konnect and was checked with a fresh KiCad netlist and ERC.

#StatusWhat changedWhy

Changes outside the fix list

  • Project file added. The folder only had a schematic, so Konnect could not tell which project owned it. I copied the parent project's .kicad_pro in, then used Konnect's rename tool so all 179 symbol records point at the "CLAUDE TEST" project. The parent project was not touched.
  • New project symbol library. StrainGauge.kicad_sym holds the corrected display symbol, registered in this folder's sym-lib-table. Your shared Custom_Lib is unchanged.
  • PWR_FLAG on +3.3VA and +5V_SYS. These rails are fed through a ferrite bead and ORing diodes, which KiCad treats as passive, so ERC reported them as undriven. The flags tell ERC where the power comes from.
  • No-connect flags on unused MCU pins. PA4, PA9, PA10, PB8–PB12 and PB14. This cleared 15 ERC errors.
  • SWD ground rerouted. Going from 4 to 6 pins moved pin 5 onto the old ground wire, which would have shorted NRST to GND. Pin 4's ground now leaves sideways.
  • Wire cleanup. Removed the stub wires and orphaned ground symbols left behind by the deleted resistors.
  • Backup. The original schematic is in backup/straingaugesystem-before-fixlist-2026-10-30.kicad_sch.

Still to check

  • Backlight colors. The datasheet text does not say which cathode (pin 2 or 13) is red. Check with a meter in diode mode. Once known, the green path can drop to 18 Ω for full brightness.
  • Reference voltage. Moving REF from 2.5 V to 1.8 V was my call. Change U6 back to REF4132B25 if you prefer the old centring.
  • Reverse polarity and D7. D9 protects the board, but a reversed battery puts about 5 V reverse across LED D7, which is at the limit of most LEDs.
  • Footprints still missing. SW2 and the DOGS102 display (J15) need footprints, and the precision parts need manufacturer part numbers.
  • Visual review in KiCad. Labels and new parts were placed by script; worth a look for layout.
  • Firmware. Pin moves: display on SPI2, I2C1 on PB6/PB7, SD detect on PA8, backlight PWM on PA2/PA3 (TIM2_CH3/CH4).
  • Remaining ERC warnings. Nine short dangling wire stubs (mostly there before) and library-version mismatch warnings. No errors.
ERC errors went from 18 to 0. Datasheets used: EA DOGS102-6 (backlight pinout and resistor table), TI INA333 (gain = 1 + 100 kΩ / RG), Diodes AP7361C, TI TPD4E05U06, ST USBLC6-2.
